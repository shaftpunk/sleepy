# Visual & functional acceptance checklist

- [ ] Screenshot matches warm ivory/blush/lavender mood, not blue/navy.
- [ ] Header, action controls and Sleep Wave read as one coherent design.
- [ ] Light and dark themes have intentional palettes and adequate contrast.
- [ ] Existing sleep start/stop, edit-time, family selection work unchanged.
- [ ] No duplicate next-sleep displays; active-sleep state makes sense.
- [ ] Chart x-values represent real time; actual sleep duration remains accurate.
- [ ] No invented upcoming naps, onset probabilities, or sleep durations.
- [ ] Short sessions and overnight records remain understandable.
- [ ] No horizontal overflow at 320 / 360 / 375 / 390 / 430px.
- [ ] Norwegian and English labels do not clip; text scaling works.
- [ ] Reduced-motion and VoiceOver text fallback remain usable.
- [ ] Safe areas and bottom navigation do not cover content.
- [ ] Production build and focused regression tests pass.
- [ ] Physical iPhone screenshot reviewed before further styling passes.
